# TechNova Website

1. Project Description
TechNova is a technology company website developed to showcase the company's services, provide information about the company and allow visitors to get in touch.

 2. Project Objectives
- Create a professional technology website.
- Provide information about TechNova.
- Display the services offered by the company.
- Make the website accessible on mobile phones, tablets and desktop computers.
- Provide an interactive and user-friendly experience.

 3. Website Pages
- **Home Page (index.html):** Introduces TechNova.
- **About Page (about.html):** Provides information about the company.
- **Services Page (services.html):** Displays the services offered.
- **Contact Page (contact.html):** Allows visitors to contact the company.

4. Technologies Used
- HTML5 – Website structure.
- CSS3 – Website styling and layout.


6. Key Features
- Multiple website pages.
- Navigation menu.
- Responsive website layout.
- CSS styling and grid layouts.
- Interactive JavaScript features.
- Contact form with validation.

7. How to Run the Project
1. Download or clone this repository.
2. Open the TechNova project folder.
3. Open index.html in a web browser.
